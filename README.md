

A browser-based password strength checker that analyzes passwords beyond basic length and character checks. It provides a detailed security analysis to help users understand password weaknesses and create stronger passwords.

## ✨ Features

* 📊 **Password Strength Scoring** — Rates passwords on a scale of 0–100.
* 🔢 **Entropy Calculation** — Estimates the randomness of a password based on its length and character pool.
* ⏱️ **Estimated Crack Time** — Provides estimated brute-force times for different attack scenarios.
* ⚠️ **Weak Pattern Detection** — Detects repeated characters, sequential patterns, and keyboard patterns.
* 📖 **Common & Dictionary Password Detection** — Checks for commonly used and dictionary-based passwords.
* 👤 **Personal Information Exposure** — Identifies whether a password contains personal details such as a name, username, birth year, or email.
* 📋 **Security Policy Compliance** — Supports NIST 800-63B, Corporate Strict, and Basic password policies.
* 💡 **Security Suggestions** — Provides recommendations to improve password strength.
* 📂 **Batch Analysis** — Allows multiple passwords to be analyzed at once and sorts results from weakest to strongest.
* 🔒 **Privacy-Focused** — All analysis runs locally in the browser. Passwords are not stored or transmitted.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Use

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser.
3. Enter a password to analyze its strength.
4. Review the score, entropy, estimated crack time, detected weaknesses, policy compliance, and suggestions.

## 📊 What It Analyzes

The Password Strength Checker evaluates factors such as:

* Password length
* Character variety
* Estimated entropy
* Common passwords
* Dictionary words
* Sequential patterns
* Keyboard patterns
* Repeated characters
* Personal information exposure
* Password policy compliance

## 🔒 Privacy

This project is designed to run entirely on the client side. Passwords entered into the application are **not stored or transmitted to any server**.
